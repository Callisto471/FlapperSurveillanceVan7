# Media

This directory contains screenshots, sample frames, and supporting media captured during development of the FlapperSurveillanceVan7 project.

## Structure

- `screenshots/`
  - Captured observations and setup references.

- `sample-frames/`
  - Individual extracted frames intended for review, annotation, or future Roboflow testing.

- `videos/`
  - Source recordings captured during feeder observation sessions.

## Notes

- Initial testing is focused on passive bird-feeder observation using consumer mobile hardware.
- Current capture testing includes indoor-through-glass recording and handheld fallback capture methods.
- Large raw video files may remain local and not be committed to GitHub due to repository size considerations.
